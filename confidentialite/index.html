Informations légales

Confidentialité

Prix d’Atelier ne vous demande ni compte, ni adresse e-mail, et n’affiche pas de bandeau de cookies parce qu’il n’en dépose pas. Cette page explique ce qui se passe quand vous utilisez les calculateurs, et où vont vos chiffres.

En bref

  • Aucun cookie.
  • Aucune donnée personnelle collectée par l’éditeur : pas de formulaire, pas de compte, pas de lettre d’information.
  • Les produits que vous enregistrez restent dans votre navigateur, sur votre appareil.
  • La fréquentation est mesurée par de simples compteurs anonymes : aucun identifiant, aucune donnée saisie.

Vos calculs et vos produits enregistrés

Les calculs se font dans votre navigateur. Les chiffres que vous saisissez ne sont envoyés à personne.

Quand vous enregistrez un produit, il est conservé dans le stockage local de votre navigateur (localStorage), sur l’appareil que vous utilisez. Ni l’éditeur ni l’hébergeur n’y ont accès. En pratique :

  • vos produits ne passent pas d’un appareil à l’autre, ni d’un navigateur à l’autre ;
  • ils disparaissent si vous effacez les données de navigation du site ;
  • vous pouvez les supprimer un par un depuis la liste de vos produits, ou tous à la fois en effaçant les données du site dans les réglages de votre navigateur.

L’export CSV est fabriqué par votre navigateur : le fichier est enregistré directement sur votre appareil.

Le lien de partage

Le lien de partage contient les valeurs de votre calcul, placées après le signe « # » de l’adresse. Votre navigateur n’envoie pas cette partie de l’adresse au serveur quand il ouvre la page. En revanche, toute personne qui reçoit le lien voit les chiffres qu’il contient : ne le partagez qu’avec qui vous voulez.

Mesure d’audience

Pour savoir quelles pages et quels calculateurs servent vraiment, le site utilise des compteurs anonymes, hébergés par le service gratuit Abacus (abacus.jasoncameron.dev). Un compteur n’est qu’un nombre qui augmente de 1 : l’éditeur ne consulte que le total de chaque compteur.

Votre navigateur envoie une requête à ce service dans les cas suivants :

  • à chaque page vue : le compteur de cette page ;
  • si vous arrivez depuis un autre site : un compteur parmi quatre (Google, Bing, autre moteur de recherche, autre site). Votre navigateur choisit la catégorie d’après le seul nom de domaine du site d’origine, qui n’est pas envoyé ;
  • la première fois que vous modifiez un calcul et obtenez un résultat, une seule fois par page affichée ;
  • quand vous exportez un CSV, copiez un lien de partage, enregistrez un produit ou imprimez un calcul ;
  • quand vous téléchargez le modèle Excel.

Ne sont jamais envoyés : les chiffres que vous saisissez, le nom de vos produits, le contenu du lien de partage, l’adresse complète de la page (ni ses paramètres, ni la partie après « # »), un identifiant ou un cookie. Le site n’écrit rien dans le stockage de votre navigateur pour cette mesure. Aucune requête n’est envoyée quand le navigateur est piloté par un programme automatique.

Comme pour toute requête sur Internet, le service de compteurs reçoit l’adresse IP de votre connexion et les informations que tout navigateur transmet d’office, comme son type et l’adresse du site Prix d’Atelier à l’origine de la requête (orielstudio.github.io). L’éditeur, lui, ne voit que le total de chaque compteur.

Le téléchargement du modèle Excel est compté de la même façon, sans rien vous demander.

Hébergement

Le site est hébergé par GitHub, Inc., société établie aux États-Unis, avec son service GitHub Pages (adresse dans les mentions légales). D’après la documentation de GitHub Pages, l’adresse IP des visiteurs est enregistrée et conservée à des fins de sécurité. Ces traitements relèvent de GitHub et sont décrits dans sa déclaration de confidentialité.

Vos droits

Le règlement général sur la protection des données (règlement (UE) 2016/679) et la loi n° 78-17 du 6 janvier 1978 relative à l’informatique, aux fichiers et aux libertés vous donnent notamment des droits d’accès, de rectification et d’effacement. L’éditeur ne détenant aucune donnée vous concernant, il n’a rien à vous communiquer : les produits enregistrés sont entre vos mains, dans votre navigateur. Pour les données techniques traitées par l’hébergeur ou par le service de compteurs, adressez-vous à eux. Vous pouvez aussi saisir la CNIL.

Droit applicable
